# Study fav — 트러블슈팅 및 방법론 검증 기록

AWSGLD vs SG-MCMC(SGLD/qSGLD/cycSGLD/SGHMC) + acMH 비교 과정에서 발견한 **평가·설계 결함과 수정**,
그리고 **"AWSGLD가 다봉에서 깊은 봉우리(낮은 min U)를 더 잘 찾는다"를 정당하게 보이기 위한 방법론 탐색**을 기록한다.

## 1. opt.gap ≈ 1.00 아티팩트 (예산-AWSGLD 결합) — **수정 완료**

### 증상
AWSGLD의 opt.gap이 설정(n·난이도)과 무관하게 거의 **1.00±0.00** (옛 CSV: 1.0072±0.0059, 전부 (1.0,1.02] 연속분포).

### 원인 (코드 확인)
- `U*`(=Umin)는 u₀에서 경사하강 8000스텝으로 **독립 계산** → U* 연동 아님, 클램프 아님.
- 진짜 원인: **예산(budget) = AWSGLD가 EPS(=1.0) 도달하는 스텝수(Tε)** 로 정의됨
  (`budget = AWSGLD reach`, 전 방법 이 예산으로 실행). AWSGLD 재실행은 같은 시드라
  reach 직전까지만 돌아 `min U ≥ U*+EPS` → **gap이 EPS에 순환 고정**.

### 실증
동일 시드·동일 U\*: 예산=Tε → gap 1.005 / 예산=고정 MAXB=3000 → gap **0.284**. (클램프 없음 확정)

### 수정
전 방법 **고정예산(MAXB=3000)** 에서 opt.gap 측정, **Tε(EPS 도달 스텝)는 "속도" 지표로 별도 기록**.
→ `opt_acmh_fair.py` / `docreal_optfair.py` / `amazon_merge_opt.py` main 수정.

## 2. Hulth 평가 정보 누출 (관측 라벨 포함 평가) — **수정 완료**

### 증상/원인
관측 Y=1을 truth의 절반에서 뽑는데 Top-k/NDCG/AUC를 **전체 truth**로 평가 → 관측분이 거의 자동 적중.

### 실증 (K=10)
관측 노드가 top-k에 드는 비율 **95%**, AUC **0.808(전체)** → **0.681(held-out)** = 약 0.13 부풀림.

### 수정
Top-k/NDCG/AUC를 **관측 노드(Y=1) 제외, 미관측 truth만**으로 평가(held-out). 랭킹 pool에서도 관측 제외.
→ `docreal_optfair.acc_metric(..., obs)` 추가.

### 부가: α 정의
Hulth·아마존의 α는 `kfa.alpha_find(u0, Y, grid)` **격자추정**(시드별 재추정). Spearman·MSE는 실데이터라
데이터생성 ts가 없어 **제외**(합성에서만 정의).

## 3. 스텝사이즈 미튜닝 — **공정 튜닝으로 정정**

### 증상
초기 비교에서 SGLD·SGHMC·cycSGLD가 크게 뒤처짐. 확인 결과 **전 실험이 미튜닝 default**
(SGLD 0.02, qSGLD 0.3, cyc 0.005, SGHMC 0.01, AWSGLD 0.3) 사용.

### 실증 (기본 n=1000, 고정예산)
LR만 바꿔도 SGLD gap 269→0.38, SGHMC 14.8→0.35. **미튜닝이 성능차의 주범**.

### 공정 튜닝 결과 (상한: SGLD≤0.6, qSGLD≤0.6, cyc≤0.05, SGHMC≤0.05, AWSGLD≤0.6)
- opt.gap: AWSGLD ≈ cyc ≈ qSGLD (0.27~0.35, 사실상 동률), vanilla는 상한 binding으로 다소 하위.
- **정확도(Top-k/AUC)는 전 방법 동률** (합성 소수 셋째자리까지 일치).
- **AWSGLD의 재현되는 강점 = LR 강건성**: default(0.3)·상한(0.6) 어디서든 gap 불변. 경쟁자는 LR에 민감.

### 결론
공정 튜닝 후 **표준(단봉) BSS 최적화에서 AWSGLD는 opt.gap·π-RMS·Tε·강건성 우위, 정확도는 동률.**

## 5. "AWSGLD 다봉 강점을 min U로 보이기" — **방법론 딜레마와 해소 (진행 중)**

연구 의도: **주제가 다른 여러 문서를 넣어도(주제 섞여도) 잘 된다** + 다봉에서 **깊은 봉우리(얕은 트랩 피해 전역최소)를 잘 찾는다**를 **min U**로 보이고 싶음.

### 5.1 표준 BSS는 볼록(단봉) → 최적화만으론 AWSGLD 특별하지 않음
U = −loglik(PU·sigmoid) + ‖B(θ−u₀)‖²/2σ². **둘 다 볼록 → min U 하나뿐**(주제 섞어도).
볼록이면 트랩이 없어 flat-histogram이 유리할 이유가 없음 → 병합(단봉)에서 정확도 동률.

### 5.2 유효한 다봉 = log-sum-exp 혼합만 (CLAUDE.md 명시)
문서별 **표준 BSS 에너지 U_k** 를 `U_mix=−logΣexp(−U_k)` 로 결합 → 봉우리 K개(문서 K개).
⚠️ **직접 가중합(ΣU_k)·단순 조작 금지**(단일 최소 발생). 모델 자체(볼록 BSS)는 건드리지 않음.
- 비교: 병합/ΣU_k = 단봉, log-sum-exp = 다봉(K basin) — `study_fav.md §4.5` 참조.

### 5.3 "문서 합쳤는데 정답이 1문서?" — 타깃 설정의 한계
타깃 1문서 + 방해 K−1 (truth=타깃 키워드) 설정은 **인위적**이고 견고하지 않음:
- 타깃 basin은 항상 **최심**이지만(깊이 진단 확인) **도달성(reachability)**이 문서마다 다름.
- K=10 타깃 1994만 도달 100%(넓은 basin), 나머지 9문서는 OBS 50%로 올려도 **도달 0%**.
  → **cherry-picking 위험**. "여러 주제 다 뽑기"와 "min U(한 봉우리)"는 **양립 불가**
  (min U = 한 봉우리 = 한 주제).

### 5.4 온도의 정당성 ⭐ 핵심 구분
| 온도 | 성격 | 정당성 |
|---|---|---|
| **T=1 (샘플링)** | 사후분포 exp(−U) 자체, **모델이 고정** | 하이퍼파라미터 아님. 단 **min U를 안 찾음**(탐색) |
| **고정 중간온도 T=0.3** | exp(−U/T), 사후도 MAP도 아닌 어중간 | ❌ **임의 하이퍼파라미터 = cherry-pick, 사용 불가** |
| **annealing T→0** | 도착점 min U(원리적), **냉각속도 τ = 스케줄 HP** | ✅ **τ는 SGD LR스케줄급 정당 HP** (전 방법 동일 적용 시 공정) |

**정정**: 초기 "annealing이 AWSGLD를 중화한다"는 과한 주장. annealing은 **T_min(1e-4)까지만** 내려가고
**식는 도중 중간온도(0.1~0.3) 탐색창을 반드시 통과** → 그 구간에서 AWSGLD가 트랩 탈출 가능.
**냉각속도(τ)를 정당한 HP로 조절**하면 min U + annealing + AWSGLD 정당화의 길이 열림.

### 5.5 참고 관찰 (중간 고정온도 — 방어 불가 데이터, 경향만)
표준 BSS 혼합 K=10, 고정 T=0.3: min U−U\* = **AWSGLD 48.1 < qSGLD 50.4 < cyc 54.3 < SGHMC 71.0 < SGLD 106.2**.
→ **AWSGLD가 깊은 봉우리를 더 잘 찾는 경향은 실재**. 단 "T=0.3"이 임의라 이 수치는 논문 불가.
→ **냉각속도별 annealing(τ=400/1200/3000)으로 재검증 중** (결과는 §5.6에 추가 예정).

### 5.6 냉각속도별 annealing 결과 ✅
`bss_anneal.py` (표준 BSS 혼합 K=10 n=322 basin=10, 전 방법 동일 τ, 고정예산 MAXB=3000, 10시드) — **min U − U\***:

| 방법 | τ=400 | τ=1200 | τ=3000 |
|---|---|---|---|
| **AWSGLD** | **11.12±2.48** | **24.16±2.41** | **69.11±2.38** |
| qSGLD | 11.16±2.48 | 25.42±2.48 | 70.73±2.44 |
| cycSGLD | 13.22±2.41 | 29.01±2.36 | 74.21±2.36 |
| SGHMC | 30.74±2.43 | 49.77±2.36 | 94.55±2.29 |
| SGLD | 73.61±3.23 | 98.49±3.17 | 137.81±3.14 |

**해석 (정당·공정: 전 방법 동일 τ, 원리적 min U 목표):**
- **AWSGLD가 전 냉각속도에서 min U 최저** → "깊은 봉우리를 가장 잘 찾는다"가 **annealing(정당)으로도 성립**.
- 단 **AWSGLD vs qSGLD 격차는 작음**(0.04/1.3/1.6) — 둘 다 preconditioner라 거의 동률. **명확한 우위는 cyc(+2~5)·SGHMC(+20~25)·SGLD(+60~70) 대비**.
- **냉각속도-예산 상호작용**: 고정예산(MAXB=3000)에선 **빠른 냉각(τ=400)이 가장 낮은 gap**(끝까지 식어 basin 안착). 느린 냉각(τ=3000)은 끝에서도 T≈0.37로 **덜 식어** gap↑. → 예산 고정이면 빠른 냉각 유리.

**결론**: 표준 BSS 혼합 + 원리적 annealing에서 **AWSGLD가 min U 최소(깊은 봉우리 탐색 최상)** 는 방어 가능.
다만 AWSGLD의 "고유" 우위(vs qSGLD)는 작고, 주된 분리는 preconditioning 유무(AWSGLD·qSGLD vs 나머지)에서 옴.

### AWSGLD = flat-histogram 전역최적화 (개념)
에너지축을 M구간(M_REGIONS=1000)으로 나눠 **방문 가중치 aw[J]를 적응 갱신**, **덜 방문한 저에너지 구간으로
미는 경사승수 gm**을 걸어 **전 에너지 레벨을 균일 방문** → 깊은 봉우리까지 훑어 **최저 min U 기록**.
annealing과 달리 온도 스케줄 없이 저에너지를 탐색(Wang-Landau). 우리 코드는 flat-histogram+Langevin+annealing 결합.

### 5.7 다봉 혼합의 min U ↔ 순위 상충 + 비볼록성 검증 ✅
- **T=1(모델 고정)·annealing(τ=400~3000) 모두 AWSGLD가 min U 최저**(깊은 봉우리 최상 탐색). K↑일수록 qSGLD와 격차↑(K30 +8.6). → "깊은 봉우리 탐색" 주장은 방어 가능.
- **그러나 순위(Top-k/AUC)는 AWSGLD 최하위**(K10 T=1: AWSGLD AUC 0.47~0.53 vs SGLD 0.57). **min U↔추출정확도 정반대**:
  AWSGLD가 "가장 깊은 한 봉우리=한 문서"에 정확히 안착 → 나머지 문서 키워드 놓침. 미수렴한 SGLD가 여러 봉우리에 걸쳐 우연히 더 맞음.
- **PU likelihood는 비볼록**(Y=0 항 `−log(1−(1−α)σ(θ))`의 2계도함수 α>0서 음수: α0.2→−0.14). 그러나
  **병합 BSS는 실측상 단봉**(Hulth K=10, 14개 랜덤시작 전부 동일 1개 지역최소) — 강한 2차 prior가 작은 비볼록성을 압도.
- → **표준 BSS 병합으론 다봉이 안 생기고, 다봉은 log-sum-exp 혼합뿐인데 거기선 추출정확도가 상충.**

### 5.8 최종 연구 방향 결정 ⭐
**병합(단봉)으로 "다주제 문서 섞여도 강건" + AWSGLD는 opt.gap·π-RMS·Tε·LR강건성 우위(정확도 동률)** 로 확정.
- 가장 안전하고 **데이터 이미 확보**(`docreal_optfair_k{1,5,15,30}` 튜닝·held-out, §study_fav.md §4.7).
- 근거: K↑(문서·주제 다양성↑)에도 **정확도 유지**(AUC 0.68~0.73, 붕괴 없음) + AWSGLD opt.gap/π-RMS/Tε 전 K 1위.
- 다봉(혼합) 트랙은 **폐기**(min U↔정확도 상충으로 "추출 잘함" 주장 불가). 깊은봉우리 탐색은 부가 관찰로만.

## 핵심 결론 (현재까지)
- **단봉(표준/병합) 최적화**: AWSGLD는 opt.gap·π-RMS·Tε·LR강건성 우위, **정확도 동률**.
- **다봉(log-sum-exp 혼합)**: AWSGLD가 깊은 봉우리(낮은 min U)를 더 잘 찾는 **경향 확인**.
  정당화 열쇠 = **표준 BSS 모델 유지 + log-sum-exp 혼합 + annealing(냉각속도 τ를 정당 HP로)**.
  (고정 중간온도·타깃 cherry-pick·모델 변형은 금지.)
- **min U vs 순위**: min U(한 봉우리)와 "여러 주제 커버"는 양립 불가. 의도가 "깊은 봉우리 탐색"이면 min U가 맞음.

## §6 α 추정 격자 문제와 시뮬레이션 참 α 재실행 (2026-10-13)

### 6.1 문제 — α 격자가 Wang 원본과 달라 시뮬 α가 과대추정
- `alpha_find(Base_Line, Y, grid)` = **θ=u₀(TextRank)에 고정한 PU 관측우도** `Σ[Y·log((1−α)σ(u₀))+(1−Y)·log(1−(1−α)σ(u₀))]` 를 α 격자에서 최대화(샘플링 전 1회 plug-in).
- **우리 격자**(`keyphrase_functions_awsgld.py`): `(k−5)/k, k=10..42` = **[0.5, 0.881]**.
  **Wang 원본**(`original/keyphrase_functions.py`): `np.linspace(0.05,0.90,33)` = **[0.05, 0.90]**.
- 시뮬 참 α(0.1~0.4)가 전부 하한 0.5 아래 → **추정 α가 0.5에 고정**(Easy/Moderate/Sparse 0.500, 기본 0.534, Difficult 0.573). "라벨노이즈 난이도" 설계 무력화.

### 6.2 조치 — 시뮬은 참 α 사용 (`TRUEALPHA=1`)
- `opt_acmh_fair.gen`: `a0 = ALPHA if TRUEALPHA else alpha_find(...)`. 실데이터는 격자 추정 유지(Hulth 0.67~0.72 격자 안쪽, 정상).
- **참 α 100시드 재실행 결과** (n=1000, 튜닝 LR SGLD/qSGLD/AWSGLD=0.6·cyc=0.05·SGHMC=0.05, MAXB=3000):
  난이도가 AUC로 정상 분리(Easy 0.960>Moderate 0.945>기본 0.912>Difficult 0.896). AWSGLD가 opt.gap·π-RMS·Tε 전 시나리오 1위, 랭킹은 동률.
  CSV: `optacmh_n1000_mu*_a*_ta*_seeds.csv`.

### 6.3 고노이즈 시나리오 추가 — "α↑ → AWSGLD 우위↑" 검증
- μ=1.2, 참 α=0.7(Hulth 수준)·0.85(Amazon 수준) 100시드.
- **SGHMC opt.gap**: α 0.1→0.85에서 0.38→**0.94**(AWSGLD 0.28의 3.4배). α=0.85에서 랭킹도 처음 열위(SGHMC AUC 0.891<AWSGLD 0.909).
- → 저노이즈는 AWSGLD 유리영역 아님이 맞고, **고노이즈(α≥0.7)가 AWSGLD 유리영역**. 실데이터(Hulth 0.7/Amazon 0.88) 격차와 정합. (n/그래프구조도 부가 기여 추정.)
- CSV: `optacmh_n1000_mu1.2_a0.7_hn07_seeds.csv`, `_a0.85_hn085_seeds.csv`.

### 6.4 σ² 처리 — 적분소거 MAP은 퇴화 → **σ²=1 고정 채택**
- Wang acMH는 σ²를 IG(0.001,0.001) prior로 **적분소거**: `U_marg=−loglik+(n/2+0.001)·log(C/2+0.001)`, `C=‖B(θ−u₀)‖²`.
- **검증(기본, seed0)**: `U_marg(u₀)=−2778.8`(C=0) vs `U_marg(θ*)=+2550.7`(C=116.5). 차 **−5329** → 라벨우도 이득(≈157)으로 못 메움.
  즉 **적분소거 posterior의 전역최소는 u₀ 옆(σ_eff²≈0), 라벨 무시**. MAP/최적화에 부적합(AWSGLD가 퇴화해로 직행).
- 원 acMH가 이를 피한 건 MAP이 아니라 **표본평균**이고 그 지점에 도달 못 해서.
- **결정**: 본 연구는 **σ²=1 고정 하이퍼파라미터**로 둔다(모든 SG-MCMC U/gradU/U*). acMH도 비교 시 동일 σ²=1 posterior(`posterior_gibbstheta(...,1.0)`)로 맞춘다. **논문에 명시**: "IG prior 적분소거는 MAP이 u₀로 퇴화하므로 최적화엔 부적합, σ²=1 고정."
